# Payroll Checker — ready-to-run Vite project

## Requirements
- Node.js 18+ (Node 20+ recommended)
- npm

## Run
```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Build
```bash
npm run build
npm run preview
```

This project includes the React/Vite app, UI components, payroll engine, Excel workbook reader/exporter, TypeScript config, and Vite config.

The app reads uploaded files locally in the browser and generates an issues-only `.xlsx` report.
